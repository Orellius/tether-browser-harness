# Tension

Tether uses an original interface grammar designed for technical SaaS tools:
**Tension**.

- Two white boundary rails and one blue-violet connection express the product:
  a controlled relationship, not general browser ownership.
- The interface has one quiet near-black ground, hairline separation, and a
  single accent reserved for a live Tether boundary.
- Oversized, tightly tracked state type makes the current condition legible
  before secondary explanation or controls.
- The Session Console stays in the isolated window so the user can see both
  scope and exit control without relying on an agent transcript.
- Status changes use a polite live region for assistive technology, avoiding an
  interruption while still exposing the change.

This is not a copy of another product's visual system. The Tether mark is an
original vector symbol: two bounded rails held together by a central connection.
